# وجه ساعة غروبي — Wear OS (Pixel Watch)

مصدر هذا المشروع في المستودع هو المجلد `wear-os/`. الحزمة `public/ghurubi-wear.zip` تُبنى منه، وجذر الأرشيف اسمه `ghurubi-wear` حتى يُفتح مباشرة في Android Studio.

الوجه يعرض **التوقيت الغروبي فقط**. لا يُرسم التوقيت الزوالي (المدني) على القرص، ولا يوجد إعداد لإظهاره.

## التثبيت على ساعتك
1. ثبّت Android Studio على الكمبيوتر وافتح هذا المجلد (File → Open). اقبل إنشاء Gradle Wrapper إن طُلب.
2. على الساعة: الإعدادات → النظام → حول → اضغط "رقم الإصدار" 7 مرات لتفعيل خيارات المطوّر.
3. الإعدادات → خيارات المطوّر → فعّل "تصحيح ADB" و"التصحيح عبر Wi‑Fi" (الساعة والكمبيوتر على نفس الشبكة).
4. في Android Studio: Device Manager → Pair devices using Wi‑Fi، أو من الطرفية:
   `adb pair IP:PORT` ثم `adb connect IP:PORT`
5. اضغط Run (▶) واختر الساعة. سيفتح تطبيق Ghurubi: وافق على إذن الموقع.
6. اضغط مطولاً على وجه الساعة الحالي → اختر **Ghurubi**.

## الاستخدام
- 12 بالأعلى = الغروب (00:00) وفي الساعات الزمانية الشروق = 12:00.
- لمسة على وسط الوجه تبدّل بين الساعات الزمانية والمتساوية (يتغير اللون: أزرق/ذهبي للمتساوية، فيروزي/برتقالي للزمانية).
- لمسة على أسفل الوجه تبدّل سطر الصلاة: وقت الصلاة الغروبي ← العد التنازلي ← إخفاء.
- تحت مركز القرص تظهر عبارة اليوم مثل «ليلة الجمعة» وتنتقل لليوم التالي عند الغروب.
- لتحديث الموقع بعد السفر افتح تطبيق Ghurubi مرة أخرى.
- الحساب على مستوى سطح البحر مثل أم القرى، والموقع الافتراضي الرياض.

## إعادة بناء الحزمة
من جذر المستودع، بعد أي تعديل على `wear-os/`:

```bash
rm -rf /tmp/ghurubi-wear public/ghurubi-wear.zip
cp -a wear-os /tmp/ghurubi-wear
(cd /tmp && zip -r -X ghurubi-wear.zip ghurubi-wear)
mv /tmp/ghurubi-wear.zip public/ghurubi-wear.zip
```
